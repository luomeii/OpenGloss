# OpenGloss

**在日常英文网页中获得词级帮助，把当天接触的词留给自己。**

OpenGloss 是一个本地运行的英语阅读辅助工具：浏览器里标注词语，悬停看释义，按需点「认识了」；小 P 留在网页旁，提供侧栏、人格和可选 AI 交流。没有必须完成的课程、测验或打卡。忙时继续读，想回顾时再打开今日识单。

> **v0.4.0 · 阶段发布候选**：提供 Windows 10/11 x64 离线安装包，扩展手动加载。文件与同源构建已有核验，最终包的干净 Windows、真实浏览器及登录自启首用仍待验证。下载时请以对应 Release 的测试状态为准。

English: Local-first vocabulary assistance for everyday web reading. Hover for definitions, record explicit feedback, and print a daily contact list. Basic assistance works without AI. Windows offline installation bundles the runtime and dictionary; the browser extension is loaded manually.

## 开始使用

### Windows：下载后离线安装

普通用户选择 [Releases](https://github.com/luomeii/OpenGloss/releases) 中单独列出的 `OpenGloss-v0.4.0-windows-x64-offline.zip`，以及同名 `.sha256` 文件。GitHub 自动生成的 Source code 压缩包没有自带运行环境和完整词典。

1. 核对 SHA256，把 ZIP **完整解压到本地可写的新目录**，不要覆盖旧安装或日用目录。
2. 双击根目录 `Install.cmd`。它离线校验自带的 Python、依赖和词典，生成四个操作入口，并尝试启动引擎。不需要系统 Python、AI 密钥、管理员权限或安装时联网。
3. 等待出现 `[PAE] engine ready: http://127.0.0.1:4815/v1/health`。文件校验成功不等于引擎已就绪；未启动时按窗口提示排查。
4. 在 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions` 开启开发者模式，选择「加载已解压的扩展程序」，加载本目录的 `pae/extension`。
5. 打开或刷新英文网页，确认扩展开关已开。基础标注无需口令、配对或连接配置。

PowerShell 校验下载文件：

```powershell
Get-FileHash .\OpenGloss-v0.4.0-windows-x64-offline.zip -Algorithm SHA256
```

把输出与同版本 `.sha256` 对照。完整安装、文件位置和卸载步骤见根目录的 [安装说明](安装说明.md)。目标浏览器的实际兼容性以该版验收结果为准，不承诺所有 Chromium 衍生浏览器均已通过。

### 启停与自启

安装根目录会生成四个明显入口；对应脚本也保留在 `pae/`，不要单独移走。

| 根目录入口 | 对应脚本 | 用途 |
| --- | --- | --- |
| `quick_start.lnk` | `pae/quick_start.bat` | 启动本安装的引擎 |
| `quick_stop.lnk` | `pae/quick_stop.bat` | 停止可确认归属本安装的引擎 |
| `autostart_on.lnk` | `pae/autostart_on.bat` | 为当前用户登记登录自启 |
| `autostart_off.lnk` | `pae/autostart_off.bat` | 取消本安装的登录自启 |

默认监听本机 `127.0.0.1:4815`。遇到其他安装占用或无法识别的自启登记时，入口会保留并提示冲突；不要为安装新版随意停止其他实例。安装器不会自动开启自启，不改系统 PATH、不创建桌面入口；只有主动开启自启才写当前用户的 Run 登记。

### 升级与回退

本版**手动下载、安装到新目录**，没有自动更新或自动数据迁移。保留旧程序，并用旧版本的备份工具为实际使用的数据库生成快照。新协议记录不应交给旧程序共用；回退用旧程序及对应旧库快照。

本包采用固定公开扩展身份。旧手动加载版可能被浏览器识别为另一扩展，旧开关和地址不保证承接：停用旧扩展、加载新版、核对设置，再刷新网页，避免两份同时标注。清单中的 `key` 是公开身份字段，不是 AI 密钥，不要自行删除。

移动安装目录前先在原目录取消自启、停止引擎，再在新位置重新安装和按需开启自启。卸载按 [离线版卸载步骤](安装说明.md#卸载离线版) 操作，先把需要保留的备份另存。

## 日常操作

| 想做什么 | 在哪里操作 | 要知道的区别 |
| --- | --- | --- |
| 看一个词 | 悬停页面标注 | 本地词典释义不需要 AI，暂不保证按句子消歧 |
| 表达目前认识 | 词卡中的「认识了」 | 后台确认后显示「已记录」；是自我反馈，不是测验结论 |
| 查看小 P | 网页右下胶囊、原侧栏 | 保留网页内位置和操作；指标描述记录，不等于真实掌握率 |
| 调整标注多少 | [轻量管理](http://127.0.0.1:4815/manage) | 每页默认最多 40，可设 8–80；实际可少于上限 |
| 改人格或静音 | 管理页入口、原人格编辑页 | 静音约束主动说话，不是所有 AI 调用的总开关 |
| 回顾或打印 | [今日识单](http://127.0.0.1:4815/daily) | 选本机日期，按 Ctrl+P 打印；不需要 AI |

本地链接须在引擎运行后打开；自定义端口时换成实际地址。页面上限由扩展按文档生命周期和剩余名额控制；后端每请求默认预算 8 是分批额度，**不是每页只能 8 个**。例如上限 10，可分为 8+2。可用词少时少标，动态页面后到内容只用剩余名额；不保证把所有生词都标出。

### 「认识了」和熟悉度代表什么

- 成功提交后，同一 **UTC 日**内重新悬停或重启引擎仍能看到「已记录」，重复点击不应重复累计。UTC 日与本地日期可能不同。
- v0.4.0 的新后端选中只记录接触，不直接增加学习证据；悬停和主动反馈继续沿用现有增量。历史旧记录保留原语义，不重新计算成新协议。
- 熟悉度 S 是依照事件、权重和时间衰减算出的辅助值。查询按既有半衰期计算当前分数，不写学习事件；长期没互动的词可能重新入选。它不是已学会的证明。
- 同批无学习状态的普通候补词中，尚未记录接触的词优先，已有词仍可补位；少互动词可能在后续页面重复出现，没有新增永久屏蔽规则。
- 无法确认提交时会提示核对或重试；实际数据库提交异常会暂停该实例的标注与学习记账，重启后从已提交记录恢复。不要把异常暂停当作正常学习模式。

### 今日识单

清单汇总指定本机日期的完整**已记录选词**，包括旧 `encounter` 和新 `contact_selected_v1`，并列出悬停、认识反馈。悬停但当天未反馈认识的词会被突出供回顾；排序不改学习分。

词义来自本地词典。本版提供中文义；英文解释和词性统一标注「未提供」，**完整离线中英双释仍是后续目标**。被选中、被画出、有机会看见、真正读懂是不同事实：今日单不冒称用户读过或学会每一词，也不会自动产生 AI 请求。

## 本版更新

相对 v0.3.7，本版重点完善反馈、接触记账、日常管理与分发，没有增加强制学习任务。

| 改进 | 使用效果 |
| --- | --- |
| 认识反馈闭环 | 等实际提交再确认；重新悬停可看到记录，异常不虚报成功 |
| 接触与学习证据分开 | 仅翻网页、后端选到词不会继续直接推高新学习分；旧历史保留 |
| 当前分数读取 | 选词、侧栏等读取按当前时间衰减，避免长期展示最后一次事件分数 |
| 页面上限与开关 | 分批遵守剩余额度，关闭后旧响应不重画，重新开启可继续使用 |
| 今日识单 | 查看与打印当天接触清单，让忙时没看的词留下可选回顾入口 |
| 轻量管理 | 状态、页面上限、静音、人格/识单入口及 AI 设置集中可见，无新增口令 |
| AI 调用控制 | 总控默认关闭，保存密钥不调用；后台用途另行许可 |
| 词典与观察记录 | 发行词典按需读取；观察事实不加入学习证据和 AI 活动计数，重放跳过它 |
| 本地运行边界 | 固定扩展来源、角色身份、提交异常保护、启停/自启归属检查有所收窄 |

运行内存优化仍在目标中。按需读取减少整库常驻成本，但本最终包尚无长时间真实阅读内存测量，不承诺固定 MiB、所有机器的最低占用或已完成全部资源优化。

## AI与数据

### 可选 AI：先手动，后台另开

在 [管理页](http://127.0.0.1:4815/manage) 填 API 根地址、模型、密钥。引擎在根地址后追加 `/v1/chat/completions`，提供方需兼容该接口；不要把完整接口路径重复填入。有效配置优先级为 `PAE_LLM_*` 环境变量 → 管理页设置 → 原配置/默认值，页面显示来源。

密钥留空会保留；清除只影响本页保存值，环境变量仍优先。保存位置默认是 `pae/user_controls.json`，为本地服务使用的明文文件，接口不回显密钥；不要提交、截图或分发它。日常用户优先使用管理页，不必修改受追踪的 `config.json`。

| 控制 | 默认/效果 |
| --- | --- |
| AI 总控 | 默认关闭；开启后才允许明确的聊天、试说等模型操作 |
| 悬停后台义项实验 | 另需许可；可能发送对应句子，结果写缓存，不改当前释义行为 |
| 主动提醒 | 默认关闭，可启用规则模板；AI 文本还需总控和主动 AI 许可 |
| 主动提醒间隔 | 可设，至少 30 分钟；只约束曝光触发的主动提醒，原门槛、日额和静音仍有效 |
| 定时巡检 | 需单独开启及对应 AI 许可；建议本版保持关闭，见已知限制 |

保存配置不触发模型。关闭总控阻止后续新调用，不撤销已发送请求。静音不是 AI 总控。没有 AI 时基础标注、词典、统计和识单可独立使用；真实提供方兼容性以实测为准。

### 本地数据与边界

默认数据库 `pae/pae.db` 保存学习事件、对话、事实及审计；备份在 `pae/backups/`，人格在 `pae/persona/`，管理设置在 `pae/user_controls.json`，外部接入密钥另在 `pae/keys.json`。首次发行包没有预置日用记录，公开词典 `dict.sqlite` 不属于用户数据库。

旧遭遇/部分悬停记录可能包含网页句子，展示事件沿用页面地址、会话和加载后经过时间字段；`page_active_ms` 不等于认真阅读时长。新接触仅记词头；视口观察不存网页地址或正文、不加学习分。展示只计本次新增绘制的高亮，视口观察要求前台连续可见采样，仍不能证明人读懂或学会。网页自行发观察消息不能代记。

基础处理在本机完成。启用模型用途后，聊天可发送提问、事实、近期词和指标，获许可的悬停实验可发送句子。服务不应转发到局域网或公网。扩展读取网页文本需要相应网站权限，浏览器权限提示是功能所需。

小 P 输入/历史、词卡精确分数与确认状态在扩展框架内显示；**网页仍能观察自己文档中的高亮范围、对应词及色档**，也能影响容器显示。这不是完整词库、密钥或聊天自动暴露，但也不是所有词级信号均对网页保密。

写入口检查同源及本包固定扩展 Origin，保留既有无 Origin 本机调用；本机免口令，外部带密钥调用及内置角色按确定身份执行。固定身份是公开信息可被复制，这是一层有限来源检查，**不是防所有恶意扩展和本机程序的强认证**。

备份默认库使用 `pae/backup.bat`，通过 SQLite 快照生成一致的备份；只覆盖数据库，人格与设置需另备。不要在运行时仅复制 `pae.db` 而遗漏 WAL/SHM。清理或分发前还要核查备份、日志、设置、密钥及自定义路径，不能把已使用的安装目录当作纯净发行源。

## 技术设计

```text
英文网页 → 扩展提取/分批请求 → 本机 FastAPI 引擎 → 本地词典与选词
           ↓ 绘制/悬停/主动反馈           ↓
       原网页标注 + 扩展框架        SQLite 事件与投影
                                      ↓
                         侧栏 / 今日识单 / 轻量管理
                                      ↓ 可选、受许可
                              兼容 Chat Completions 的模型
```

- **事件与投影**：记录追加事件，派生学习与接触状态。新接触不等于学习证据；旧事件保留原含义。查询分数按时间衰减，历史调参重放仍有下述限制。
- **按需词典**：校验过的发行词典按需查释义；自建或其他兼容词典可能仍整库加载，不能把发行包的资源表现推广到所有词典。
- **页面生命周期**：扩展管理每页剩余额度、开关与在途响应，后端限制每请求预算；不新增服务端跨请求页面总额状态。
- **观察与调度**：展示/视口观察由扩展内部生成；新增视口观察不计入 AI 活动门槛，也不参与学习重放。
- **有界能力**：HTTP 与 stdio/MCP 共用能力面；参数提案受权限、范围、冷却与有效期约束。学习写入有事务故障保护，不代表所有共享状态均已获得无限并发保证。

| 目录/文件 | 定位 |
| --- | --- |
| `pae/extension/` | 扩展、标注、词卡、网页内小 P |
| `pae/pae_core/` | API、学习事件、能力、人格与 AI 接缝 |
| `pae/config.json` | 公开默认配置，不写入分发用真实密钥 |
| `resources/ECDICT/` | 词形资料；完整词典另下载或随离线包提供 |
| `distribution/` | 输入锁、离线构建器及安装器 |
| `scripts/build_dict.py` | 源码用户构建词典 |
| `skills/pae-bridge/SKILL.md` | 外部 AI 接入说明 |

`pae` 是保留的内部代号，目录、数据库、环境变量和能力名沿用它，避免无关的兼容性变化。

## 源码与开发

源码运行需要 Python 3.10+；Windows 离线包使用 Python 3.12 和锁定依赖。源码可用于其他系统，但不据此宣称本版 Linux/macOS 首用已验收。

1. 获取仓库，在根目录执行 `python -m pip install -r requirements.txt`。本版构建/隔离验证采用 FastAPI 0.115.12、Pydantic 2.11.4 等，完整组合见 [输入锁](distribution/inputs.lock.json)；最低版本范围不表示所有新组合均通过。
2. 从 [v0.3.1 词典附件页](https://github.com/luomeii/OpenGloss/releases/tag/v0.3.1) 下载 `dict.sqlite`，放入 `resources/ECDICT/`。离线安装资产已经自带，无需重复下载。也可依 [词典说明](resources/ECDICT/README.md) 准备 CSV，再运行：

   ```text
   python scripts/build_dict.py --csv resources/ECDICT/ecdict.csv --out resources/ECDICT/dict.sqlite
   ```

3. 进入 `pae/`，Windows 可用 `start_engine.bat`；通用手动启动命令为：

   ```text
   python -m uvicorn pae_core.api:app --host 127.0.0.1 --port 4815
   ```

4. 按前面的步骤加载扩展并刷新网页。缺失或损坏词典时 health 应返回未就绪，不是安装成功即可忽略。

维护者构建离线包：按输入锁的公开 URL、大小及 SHA256 准备文件，再执行 `python distribution/build_release.py --inputs <输入目录> --output <新输出ZIP>`，详见 [安装说明](安装说明.md#维护者重新打包)。锁中 `baseline_commit` 是构建来源的历史基准，不是完整最终源码的唯一身份；修改锁定源码须同步对应哈希并重新构建。

开发测试另装 `requirements-dev.txt`，从 `pae/` 可运行 `python -m pytest pae_core -q`；浏览器测试按对应脚本准备 Playwright。**历史 Windows 全量测试入口 `pae/tests/nightly.py` 可能停止或重新启动 4815 上的实例，只能在独立测试环境运行。**源码包含测试，普通离线资产不包含开发测试与样本。

外部接入可在 `pae/` 使用 `python -m pae_core.keys issue ext:名称` 签发密钥，按 [桥接说明](skills/pae-bridge/SKILL.md) 调用；JSON HTTP 请求应发送 `Content-Type: application/json`。不要把外部密钥当作网页基础使用的前置条件。代码中的内部评审编号是历史溯源线索，不代表私有规划文档已随产品发布。

## 边界与排查

本版优先稳定的阅读辅助，不承诺应试提分、自动掌握、完整上下文消歧或所有历史缺陷已清零。

| 情况 | 说明/处理 |
| --- | --- |
| 装好但没有标注 | 看安装窗口是否真正 ready、扩展是否启用、是否加载本目录，再刷新英文网页；受保护浏览器页面不作标注保证 |
| 端口冲突 | 默认 4815，先核对归属，不停止未知实例。只改启动端口不等于启停/自启全套已隔离；非默认生命周期不作完整支持声明 |
| 今日单与侧栏日期不同 | 今日单用本机日；趋势、配额及认识反馈去重用 UTC 日，UTC+8 地区早上8点换日 |
| 有接触但没有学习分 | 新选中只记接触；没有悬停/反馈的词可显示尚无学习评分，也可能重复标注 |
| AI 没回复 | 检查总控、有效配置来源、根地址和模型；基础标注不依赖 AI |
| 关闭 AI 后仍有已发请求完成 | 关闭只阻止后续请求，不撤回已发送请求；静音也不等于总控 |
| 文件配置改了没生效 | `annotate_max_s`、`max_ann_per_page`、`daily_say_cap` 的文件初始值读取有已知缺陷，参数层初始仍为 0.75/40/10 再叠加保存设置。页面上限用管理页，不在本版突然激活旧自定义值 |
| 开启自动调参后重启分数变化 | 运行和历史重放可能按不同参数解释记录；缺陷保留，建议关闭定时巡检，不保证旧覆盖自动清除 |
| 临时记忆过期仍被检索 | 活动/检索路径有 TTL 遗留缺口，不能当作已完成到期移除；敏感临时事项不要依赖自动过期 |
| 后台模型额度 | 义项实验的日150计数按成功结果，不是实际尝试次数硬上限；无硬费用保证，需要限制时保持后台许可关闭 |
| 上下文很长 | 词表可裁为空以结束裁剪，其他固定资料仍可能超预算；估算不是模型硬长度保证 |
| 长期使用资源成本 | 接触去重集合会增长，部分熟悉度统计同步重算；大历史的内存及响应仍需长期测量，API异常超大输入也没有完整容量防护 |
