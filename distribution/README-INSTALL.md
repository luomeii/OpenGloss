# OpenGloss Windows 安装候选 0.5.0-rc.1

适用于 Windows 10/11 x64。安装包包含锁定的 Python 运行时、依赖和公开词典，目标电脑无需另装 Python、pip 或 Git。本版仍是候选：全新 Windows、真实浏览器/模型、正式 GitHub Release 更新与长期运行尚待验收。

## 安装与配对

1. 将完整 `OpenGloss-windows-x64.zip` 解压到新文件夹，双击 `Install.cmd`。默认安装到 `%LOCALAPPDATA%\OpenGloss`；仅当前用户桌面快捷方式可能创建。快捷方式创建失败会显示警告，安装仍继续。首次启动以安装器报告就绪为准。
2. 管理页显示本实例引擎地址和访问口令。点击「复制访问口令」，在新版扩展弹窗填写地址和口令；无需打开扩展控制台。管理页口令与引擎访问口令不同，不要把任一口令发给网页。旧扩展必须换新版重新配对。
3. Chrome/Edge 的扩展页开启开发者模式，从此安装 `versions/当前版本/app/pae/extension` 加载扩展。扩展今后仍需手动切到新版目录并重新加载。夸克兼容性尚待独立验收。
4. 普通英文网页上可标注与悬停。默认引擎地址为 `http://127.0.0.1:4817`，管理页端口为 4818。面板从管理页打开。引擎只监听回环，所有业务 API 需 Bearer 访问口令；健康页匿名响应不会暴露数据库路径。

程序在 `versions/版本号`；此实例数据库、人格、配置及凭据在 `data`。安装包不含任何用户凭据。安装器不自动读取或迁移其他实例，也不修改系统 Python/PATH、浏览器配置或现有自启。关闭管理页标签不会关闭引擎；用「关闭此实例」结束，之后可通过本实例快捷方式再打开。

## 隐私、模型和数据

管理页可选完整网址、仅域名、哈希、不保存可读网址；最后一档仍保留内部去重标识。阅读上下文保存可关闭；悬停句子送模型做义项判定默认关闭。保存后重启此实例。这些设置不清除旧库或备份。聊天与人格等模型功能仍可能向已配置的模型服务外发相关内容。模型配置在此安装 `data/config.json`，请自行填写 `llm.base`、`llm.model`、`llm.key`，再重启。安装版不继承终端 `PAE_LLM_*` 或代理变量。

「开机静默启动」默认关闭。打开后只在当前用户的 HKCU Run 登记此实例；关闭或卸载会撤销本实例登记。升级和回退会将登记指向当前版本。

「打开数据目录」仅打开此实例 `data`。「导出数据包」先停止此实例写者，使用 SQLite backup 生成一致的数据库，再打包配置、人格和必要凭据；随后恢复引擎。导出 ZIP 仅在本机通过受保护下载提供，包含个人信息及可能的 API key，请妥善保管。运行中不要直接复制 `pae.db`、WAL 或 SHM。

卸载需明确确认，默认保留 `data`；要删个人数据需额外勾选并再次确认。卸载助手只处理经清单验证的此安装目录和本实例快捷方式/自启，不会删除解压源目录、浏览器 profile 或其他安装。

卸载安排前会建立结果文件，状态最初为 `pending`（未确认完成）。管理页同时给出 `%TEMP%` 下的 `Continue-uninstall.cmd`，请保存其位置且暂不清理该助手目录。保留数据时结果在此安装 `data/uninstall-status.json`；删除数据时结果在助手临时目录。

助手持有管理锁与数据所有权，先核对本实例自启命令与桌面快捷方式，再写入持久卸载日志；删除入口前再次核对。删除中途失败时不再要求残缺程序通过原完整性校验，而按原日志检查剩余程序的路径、内容与链接边界。关闭此实例并排除文件占用后，双击保存的 `Continue-uninstall.cmd` 继续。重试不能改变最初是否删除个人数据的选择；日志错误、外来文件或内容变动会拒绝继续，不用强制删除绕过。

结果中的 `complete:true` 才表示此次操作确认完成；`program_removed:true` 表示程序已删除，入口被外部改动时仍可能需要人工处理。`program_removed:null` 表示未确认删除状态。一次性超时报告器在约五分钟仍无终态时写 `unconfirmed`，不等于断定失败，更不等于成功；原助手仍在工作时继续操作会受到所有权锁限制。临时目录被清理后，继续入口也会失效，需保留安装根和日志交给维护者核对。

完成后安装根可能保留 `manager.lock`、`data-owner.lock` 和无口令的 `uninstall-in-progress.json` 完成凭据，用于尾部中断与重复执行判定；保留数据模式还会保留 `data`。这些是运行时文件，不属于原始发行包。确认助手退出且无该实例进程后，可自行归档保留数据并清理空余安装根；不要直接向残留根目录覆盖安装。

## 更新、回退与旧试用版

启动时仅查询公开 GitHub Release 的较新正式版本；预发布不进入自动提示。若仓库尚无正式 latest，会显示「暂无可用正式版本」；断网、证书错误和限流显示固定类别，不影响正在运行的引擎。下载需固定资产、大小及 SHA256 匹配；切换前停止本实例并备份。新版启动失败会尝试回退。回退还原更新前数据；回退前的较新数据另留备份。

若更新恢复失败，业务保持暂停。从完整解压包运行 `Recover.cmd`，按提示输入需要恢复的此实例目录；或运行 `Recover.cmd --root "此实例安装目录"`。该入口重新尝试已有更新日志的恢复，确认旧程序完整后才报告完成，但不会启动引擎。成功后再从本实例入口启动。备份缺失或占用未排除时不要强行启动旧程序。

**0.4 试用安装不能假定由旧管理器直接升级到 0.5。** 旧管理器探活依赖匿名健康响应中的数据库路径且不发送 Bearer；0.5 的安全协议会使旧管理器无法验证新引擎并可能回退。0.4 试用者请下载新的自包含包到独立目录，并手动评估旧数据迁移；本安装器不会接管或迁移旧实例。0.5 管理器从此版本开始使用带 Bearer 的身份探活，供后续版本更新验证。

独立试用无需停止旧实例，但必须分开安装目录、数据目录和端口。旧库在新版本直接打开的兼容性尚未验收，本轮不提供自动迁移器或旧网址清洗。需要备份旧数据时使用旧实例自己的安全导出，或有序关闭对应实例后备份完整数据目录，不假定旧数据在默认位置。新版卸载只卸载新版自身，不能用来卸载旧版。引擎仅应绑定 `127.0.0.1`，不要改为 `0.0.0.0`。

## 独立试用

在解压目录使用新目录和独立端口：

```powershell
.\Install.cmd --root ".\OpenGloss-Trial" --port 54975 --no-shortcuts --no-launch
```

再次执行并去掉 `--no-launch` 可启动管理页；管理页端口为引擎端口加一。`--port` 只用于首次安装。同一目录不能混装不同版本；更新须从新管理页发起。首次试用应选不存在的新目录。端口占用会报错，不停止占用者。

分享软件只发原始 Release ZIP，不要分享安装后目录、`data`、备份或日志。源代码 ZIP 不等于可安装包。
