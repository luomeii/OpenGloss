# OpenGloss Windows安装候选

适用于Windows 10/11 x64，自带官方Python运行时、固定依赖和完整公开词典；目标电脑无需安装Python、pip或Git。首次安装与词级辅助可离线使用，模型和检查/下载更新需要相应网络。

这是 **0.4.0-rc.3发布候选**，尚未完成全新系统、真实浏览器和长期使用验收。仓库源码ZIP与安装包不同；安装包固定名为OpenGloss-windows-x64.zip。

## 安装与第一次阅读

1. 将完整ZIP解压到新文件夹，不要只取出Install.cmd。
2. 双击Install.cmd。默认安装到%LOCALAPPDATA%\OpenGloss，创建当前用户桌面快捷方式并打开管理页。首次加载词典需要等待，以安装器报告就绪为准。
3. 浏览器扩展需手动加载：Chrome的chrome://extensions或Edge的edge://extensions开启开发者模式，选择安装目录versions/当前版本/app/pae/extension。夸克兼容性尚待独立验收。
4. 安装包扩展默认连接http://127.0.0.1:4817，管理页4818。默认安装无需填写地址；端口占用会报错，不停止占用者。
5. 打开普通英文网页，等待标注并悬停看释义。引擎健康地址为对应引擎地址加/v1/health，返回的db路径应属于此安装。

关闭管理页标签不会关闭引擎，用管理页「关闭此实例」结束。再启动可用桌面快捷方式，重复启动会重开此实例管理页。

## 数据与可选模型

程序在versions/版本号，个人数据库、人格、配置和密钥文件在data。安装器不自动读取或迁移旧目录数据，不修改系统Python/PATH，不设置开机自启。

标注、词典释义和统计无需API key。聊天需在管理页显示的data/config.json中补充llm.base、llm.model、llm.key，保留其他配置，保存后重启此实例。安装版不继承父进程PAE_LLM_*或代理设置，不要只在终端设置key。

配置模型后，对话、人格、事实和相关上下文可能外发；悬停句子也可能用于后台义项判定影子实验（最多300字，日上限150次），静音不关闭此路径。无使用数据遥测；管理器仍会连接公开GitHub。Key以本机配置明文保存，请私下保存data及备份。

## 更新与回退

启动时查询luomeii/OpenGloss公开GitHub Release；展示更高正式版本及说明，只有用户确认才下载。发行者须提供固定名OpenGloss-windows-x64.zip，GitHub须提供资产SHA256；预发布版本不会自动推送，没有合格资产则说明无法自动安装。

断网、下载或校验失败不切换程序。切换前停止此实例，用SQLite backup API保存数据；新版启动失败时尝试恢复旧版和备份，并显示结果。旧版本和备份占用额外空间，目前需用户自行管理保留量。

**回退同时恢复更新前的数据快照**，更新后新增记录不会出现在回退后的当前库中；回退前的最新数据会另存备份。不要把回退当作只切程序。

扩展仍需手动切换到新版目录并重新加载，引擎不会静默安装或更新扩展。

## 独立试用与自定义端口

在解压目录打开终端，例如：

```powershell
.\Install.cmd --root ".\OpenGloss-Trial" --port 54935 --no-shortcuts --no-launch
```

这只安装到指定新目录，不创建快捷方式、不立即启动。要启动并打开管理页，可在同一解压目录再次运行：

```powershell
.\Install.cmd --root ".\OpenGloss-Trial" --port 54935 --no-shortcuts
```

管理页为54936。不要选日用项目或其他已用数据目录；首次试用应选尚不存在的新目录。--port只用于新安装，同一安装重复执行不会更改已保存端口。

**扩展弹窗没有地址输入框。** 自定义端口后，在浏览器扩展页打开此扩展「Service Worker / 检查视图」控制台，执行并刷新英文页面：

```javascript
chrome.storage.local.set({ paeBase: 'http://127.0.0.1:54935' })
```

将示例替换为实际引擎地址。源码扩展默认4815，安装包默认4817，请区分加载目录。

## 备份、故障与分享

手工备份：在管理页关闭此实例，确认退出后复制整个data目录；运行中不要仅拷pae.db，最新写入可能在WAL。data/backups也可能含旧数据和key。

启动/重启失败先看此实例data/engine.log和data/manager-error.log。异常退出后可从管理页手动重启，当前不承诺自动崩溃重启。令牌失效时用快捷方式重新打开。

引擎仅监听本机回环，HTTP API默认无鉴权，不要暴露到局域网或公网。管理页限制不等于引擎API或页面桥已完全加固。真实浏览器、模型、正式GitHub安装资产和长期表现仍需验收。

分享软件只发原始Release ZIP，不要重新打包用过的安装目录、data、备份或日志。删除解压文件夹不等于删除已安装数据；卸载前先关闭此实例并确认正确安装路径。
