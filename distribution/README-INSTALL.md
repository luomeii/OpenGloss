# OpenGloss 0.5.0-rc.4 · Windows 使用说明

在英文网页上自动标出生词，悬停看释义，熟悉后点「认识了」。基础阅读不需要模型 key。此包包含运行环境、依赖和公开词典，Windows 10/11 x64 无需另装 Python、pip 或 Git。

这是待审核候选，未发布；具体测试结果见随附验收记录。

## 开始使用

1. 将完整 `OpenGloss-windows-x64.zip` 解压到新文件夹，双击 `Install.cmd`，等待出现 `OpenGloss engine is ready`。首次词典加载需要时间。默认安装位置是 `%LOCALAPPDATA%\OpenGloss`，终端会显示实际位置。
2. 打开浏览器扩展页（Chrome：`chrome://extensions`；Edge：`edge://extensions`），开启开发者模式，选择「加载已解压的扩展」，选中**安装目录根下的 `extension` 文件夹**。
3. 打开或刷新普通英文网页，开始阅读。无需填写地址或口令。网页右下角「OpenGloss · 侧栏」可直接展开；浏览器扩展菜单中的 OpenGloss 图标也能打开当前网页侧栏，固定到工具栏后更容易找到。

浏览器内置页、PDF、文件页和本机管理页不标注。夸克等其他 Chromium 浏览器需分别验收，不能用 Edge 的结果代替。扩展仍需手动加载，安装器不更改浏览器设置。

本次 rc.4 修复三处可靠性问题：停止会有界等待正在进行的操作；恢复中不提前报失败；没有可用历史版本/备份时回退不可用，后台校验失败也不会先停止引擎。算法与默认学习参数不变。

## 安装目录中的四个脚本

| 文件 | 双击后的作用 |
|---|---|
| `quick_start.bat` | 启动此实例；已运行时不会重复启动 |
| `quick_stop.bat` | 有序停止此实例的引擎和管理器；已停止时可重复执行 |
| `autostart_on.bat` | 为当前用户注册此实例的开机静默启动 |
| `autostart_off.bat` | 撤销此实例的开机启动 |

开机自启默认关闭。脚本使用包内 Python，不依赖系统 Python；启动和自启不会自动打开管理网页。若本实例正忙，停止最多等待约40秒取得关闭机会；持续忙碌会提示稍后重试，不强制中断更新/恢复。关闭获准后另行等待端口释放。其他失败也会显示提示，不按端口强杀其他程序。安装完成后的 `Install.cmd` 也可用来启动此实例。

程序位于 `versions/版本号`，个人记录与配置位于 `data`，浏览器始终加载根下 `extension`。请保留整个安装目录，不要单独移动脚本。

## 可选管理页和人格面板

默认管理页：`http://127.0.0.1:4818/manage`；人格面板：`http://127.0.0.1:4817/panel`。两者直接打开即可，不要口令。使用独立端口时，扩展弹窗会给出对应入口。

管理页可重启或停止此实例、管理自启、打开数据目录、导出、检查更新、回退和卸载；这些都是可选维护操作，不是标注的前置步骤。关闭网页标签不会停止后台，用 `quick_stop.bat` 或管理页停止。

角色名、口吻可在人格面板调整。聊天需要使用者自行编辑此安装 `data/config.json` 的 `llm.base`、`llm.model`、`llm.key` 后重启。基础词典不需要模型；未配置时不会生成真实模型回复。安装版不继承终端的模型密钥、代理或其他项目路径。

## 更新和回退

启动时检查公开 GitHub Release，管理页展示较新正式版的说明，由你选择更新。候选预发布不参与自动提示。无可用正式版或检查失败不影响阅读；本候选未发布，因此不能把当前「暂无正式版本」当更新故障。

下载验证固定资产、大小和 SHA256，切换前停止本实例并做一致备份。安装根脚本与扩展随版本同步；更新后在扩展管理页点击**重新加载**，不需要改扩展路径。不会静默安装浏览器扩展。回退恢复更新前数据，回退前的新记录会另留备份。

若恢复无法确认，业务保持暂停。从完整解压包运行 `Recover.cmd`，按提示输入本实例目录；恢复成功后再启动。备份缺失或文件被占用时不要强行覆盖。旧版安装请另设目录和端口试用，本安装器不读取、接管或自动迁移旧数据。

## 数据、隐私与卸载

默认会在本机保存阅读页面标识、部分文本上下文和交互事件；S 值是规则计算的参考，不是记忆或掌握证明。管理页可调整新记录的 URL 和上下文保存方式，设置不会删除旧记录或备份。模型启用后，聊天及已启用的模型功能可能向你选定的服务发送内容。

服务只绑定回环地址，保留 Host、Origin 和 JSON 请求边界。无口令模式面向本机单用户使用，不能隔离同一用户的其他程序或浏览器扩展。不要改为公开监听。

导出会先停止此实例写者，做一致 SQLite 备份，再恢复服务。导出包可能包含阅读足迹、对话、人格和模型 key，请私下保管。运行中不要仅复制 `pae.db`；应使用导出，或有序停止后备份完整 `data`。

管理页卸载默认保留 `data`，删除个人数据需额外选择。卸载前会显示结果文件和 `%TEMP%` 下的 `Continue-uninstall.cmd`；请保存入口且暂不清理助手目录。被占用导致中断时，排除占用后用此入口继续，它只处理有归属清单的本实例文件。`complete:true` 才表示确认完成；超时只表示尚未确认。日志与锁文件可能留在安装根。扩展需在浏览器中自行移除。

## 独立试用与故障处理

需要避开现有实例，可在解压目录执行：

```powershell
.\Install.cmd --root ".\OpenGloss-Trial" --port 54975 --no-shortcuts
```

该示例引擎端口为 54975，管理端口为 54976。不要复用现有数据目录。重复安装同版不会重建个人数据；不同版须通过更新流程。端口占用会报错，不会停止占用者。

无标注时先点扩展图标查看服务状态，确认开启标注、网站访问权限与普通 HTTP(S) 网页，然后刷新网页。服务临时未就绪会自动重试；脚本报错可查看本实例 `data/engine.log` 或 `data/manager-error.log`。无可用词、已熟悉词或页面结构限制也可能没有标注。

**分享软件只发原始发行 ZIP。安装后目录、个人 data、导出、备份与日志都不能作为净安装包分享。仓库源码 ZIP 不等于可安装包。**
