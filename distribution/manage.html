本机引擎

打开人格面板

扩展需手动加载：在浏览器扩展页开启开发者模式，选择安装目录 versions/当前版本/app/pae/extension。安装包扩展默认连接4817，无需填写地址；更新扩展后需手动切换新版目录并重新加载。夸克兼容性尚待验收。

自定义端口：扩展弹窗没有地址输入框。请打开此扩展的「Service Worker / 检查视图」控制台，执行下方命令，将示例换成上方实际引擎地址，再刷新英文页面。

chrome.storage.local.set({ paeBase: 'http://127.0.0.1:4817' })

默认端口安装无需此步骤。

标注、释义和统计不需要 API key。若要聊天，请在此安装的数据目录 data/config.json 配置自己的模型提供商，再点击「重启引擎」。配置文件保存在本机；配置模型后，对话及相关上下文、部分悬停句子可能发送给所选模型服务。安装版不继承终端的PAE_LLM_*变量。
